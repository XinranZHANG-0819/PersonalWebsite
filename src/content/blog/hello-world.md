这是我的个人网站，用来写文章、整理笔记，也追踪我关心的市场指标。

## 怎么写文章

每篇文章是 `src/content/blog/` 目录下的一个 Markdown 文件。文件开头用 `---` 包起来的部分写文章信息：

```md
---
title: 文章标题
description: 一句话摘要，会显示在列表和分享卡片里
date: 2026-10-05
tags: [投资, 读书]
draft: false
---
```

把 `draft` 设为 `true`，文章就不会出现在网站上，适合写到一半的草稿。

## 支持的写法

- 标题、列表、引用、表格和代码块
- 图片：放进 `public/images/`，用 `![说明](/images/a.png)` 引用
- 行内代码，比如 `npm run dev`
