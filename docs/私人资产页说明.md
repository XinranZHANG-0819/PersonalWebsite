# 私人资产页（/me/）

`https://xinran.wiki/me/` 是只有站长能看的资产看板。

- 页面本身是空壳，不含任何个人数据，搜索引擎也不收录（noindex、robots.txt、不进 sitemap）。
- 数据只存在 Cloudflare D1 里，**不进 GitHub 仓库**（仓库是公开的）。
- 进页面要输口令。口令只在服务器上校验；登录后发一个 7 天有效、只发给 `/api/me` 的 HttpOnly cookie。
- 同一访客 15 分钟内输错 5 次、或所有人 15 分钟内一共输错 50 次，就暂停登录 15 分钟。
- 收益、年化、和沪深300 的对比、操作建议，都在浏览器里用数据和站点公开行情现算；行情每天由数据机器人更新，建议跟着变。

## 一、Cloudflare 里要做的（一次）

在 Pages 项目 → Settings → Variables and Secrets 里加（Production，需要的话 Preview 也加）：

| 变量名 | 类型 | 说明 |
| --- | --- | --- |
| `ME_PASSWORD` | **Secret** | 登录口令，至少 12 位，建议 16 位以上的随机串。改了它，所有已登录的设备都会被踢出 |
| `ME_UPLOAD_TOKEN` | Secret（可选） | 给自动上传数据用的令牌，至少 24 位。不设就只能在页面里手动导入 |

已有的 `DB`（D1 绑定）和 `IP_SALT` 继续用，不用新建数据库，表会自动建。

**加完变量后要重新部署一次**，新变量才会生效。

没设 `ME_PASSWORD` 时，页面会显示「私人页还没开启」，接口返回 503，不会泄露任何东西。

## 二、第一次使用

1. 打开 `https://xinran.wiki/me/`，输入口令。
2. 页面提示「还没有数据」，点「选择数据文件」，选数据文件（`.json`）导入。
3. 导入后页面立刻显示。

## 三、每周更新

二选一：

- **手动**：在页面底部点「导入新数据」，选新的 `.json` 文件。
- **自动**（设了 `ME_UPLOAD_TOKEN` 才能用）：

```bash
curl -X PUT https://xinran.wiki/api/me/data \
  -H "Authorization: Bearer $ME_UPLOAD_TOKEN" \
  -H "content-type: application/json" \
  --data-binary @me-data.json
```

服务器保留最近 60 份数据，页面显示最新一份。

**数据文件绝对不要提交到仓库。**

## 四、数据格式（version 1）

下面的数字都是**示例**，不是真实数据。

```json
{
  "version": 1,
  "asOf": "2026-10-31",
  "source": "数据来源说明，显示在页面底部",
  "accounts": {
    "invest": {
      "name": "个人理财账户", "color": 2, "annual": 12000,
      "deposits": [{ "date": "2026-01-01", "amount": 12000 }],
      "cash": 5000, "cashNote": "用来补缺口",
      "classes": [
        { "id": "cn-stock", "name": "A 股", "target": 30, "note": "尚未买入" },
        { "id": "cn-bond", "name": "国内债", "target": 30, "note": "2 只债券基金" },
        { "id": "us-stock", "name": "纳指 100", "target": 20 },
        { "id": "gold", "name": "黄金", "target": 15 },
        { "id": "btc", "name": "比特币", "target": 5 },
        { "id": "us-bond", "name": "美债", "target": 0, "hidden": true }
      ],
      "extra": [{ "name": "手续费等", "note": "按现金余额倒推", "pnl": -10 }],
      "trades": [{ "date": "2026-10-12", "name": "某债券基金", "note": "某券商", "side": "买入", "amount": "1,000.00" }]
    },
    "pension": {
      "name": "个人养老金", "color": 1, "annual": 12000,
      "deposits": [{ "date": "2026-01-01", "amount": 12000 }],
      "cash": 12000, "cashName": "养老储蓄", "cashNote": "2026 年存入，待投",
      "classes": [{ "id": "fof", "name": "养老目标 FOF", "note": "2 只" }],
      "extra": [{ "name": "已清仓 · 某基金", "note": "已实现", "pnl": -50 }],
      "yearly": { "cols": ["2026", "2025"], "rows": [["某基金", -2.5, 20.1], ["合计", -3.0, 19.8]] },
      "trades": []
    }
  },
  "holdings": [
    { "account": "invest", "class": "cn-bond", "name": "某债券基金", "amount": 1001.2, "pnl": 1.2, "ret": 0.12, "m1": 0.3 },
    { "account": "pension", "class": "fof", "name": "某养老 FOF", "amount": 40000, "pnl": 4000, "ret": 11.1, "m1": -5.0 }
  ],
  "flows": [
    { "date": "2023-01-09", "account": "pension", "amount": 24000, "note": "首次买入" },
    { "date": "2026-10-31", "account": "invest", "amount": 5000, "note": "未投现金从这天起计入" }
  ],
  "monthly": [["2023-01", 23700], ["2023-02", 23300]],
  "cashAssets": { "amount": 20000, "prev": 18000, "prevLabel": "9 月", "asOf": "10-17" },
  "spending": { "month": "2026 年 10 月", "total": 2000, "budget": 3000, "count": 80, "cats": [["餐饮", 800], ["出行", 700]] },
  "settings": { "pensionProduct": "偏股养老基金", "rebalanceMonth": 12 }
}
```

### 字段说明

- `asOf`：数据截至哪天（YYYY-MM-DD）。
- `accounts.<账户>`：`invest` 理财账户、`pension` 养老金。
  - `cash`：账户里没投出去的现金。账户总值 = 各持仓 `amount` 之和 + `cash`。
  - `classes`：资产大类。`target` 是目标占比（%，只作参考）；`id` 决定用哪条建议规则：`cn-stock`、`cn-bond`、`us-stock`、`gold`、`btc`、`us-bond`。
  - `extra`：不对应持仓、但算进收益的项，比如手续费、已清仓的盈亏、利息。账户收益 = 各持仓 `pnl` 之和 + `extra` 的 `pnl` 之和。
  - `deposits`：每年存入，用来显示「今年存入 x / annual」。
  - `yearly`（可选）：历年收益表，数字是百分比，没有就写 `null`。
- `holdings`：每只产品一行。`amount` 市值，`pnl` 持有收益，`ret` 持有收益率（%，收益 ÷ 成本），`m1` 近 1 月涨跌（%）。
- `flows`：**钱进入统计的日期和金额**，用来算年化（XIRR）和时间加权收益。
  - 2026-10-31 以前：按**买入日**和买入金额（含手续费）。
  - 从 2026-10-31 起：没投的现金在这天计入；以后每年 **1 月 1 日**存入的钱，在 1 月 1 日计入，不管有没有投出去。
  - 账户之间、产品之间的调仓（比如赎回 A 再买 B）不算 flow。
- `monthly`：每月末「计入统计的市值」，按 `[月份, 金额]` 排列。口径要和 `flows` 一致：计入了的钱都要算在市值里（包括没投的现金）。
- `cashAssets`：两个账户以外的现金（银行、微信等减去负债）。
- `spending`：当月支出，`cats` 按 `[分类, 金额]`。
- `settings.pensionProduct`：养老金建议里写的产品名；`rebalanceMonth`：年度再平衡的月份。

### 校验

上传时服务器会检查：`version` 必须是 1，`asOf` 格式，`accounts`、`holdings`、`flows`、`monthly` 的结构，文件不超过 300 KB。格式不对会直接拒绝，原来的数据不受影响。
