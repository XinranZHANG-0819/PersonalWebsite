# 批注功能：部署说明（给部署的人）

文章页可以让读者选中文字写批注，作者在 `/admin/` 回复、隐藏、删除。后端是 Cloudflare Pages Functions + D1 数据库 + Turnstile 人机验证 + Access 登录保护，全部有免费额度。代码在 `functions/`、`src/scripts/annotate.ts`、`src/pages/admin/`。

## 要在 Cloudflare 里做的 4 件事

### 1. 创建 D1 数据库并绑定
1. Cloudflare 控制台 → Storage & Databases → D1 → Create，名字随意（建议 `xinran-annotations`）。
2. 打开 Pages 项目 → Settings → Bindings（Functions）→ Add → D1 database。
3. 变量名必须是 **`DB`**，选刚创建的数据库。Production 和 Preview 都加。
4. 不需要手动建表，第一次有人访问接口时会自动建表。

### 2. 开通 Turnstile（人机验证）
1. 控制台 → Turnstile → Add widget，域名填 `xinran.wiki`，模式选 Managed。
2. 得到 Site Key 和 Secret Key。
3. Pages 项目 → Settings → Variables and Secrets：
   - `PUBLIC_TURNSTILE_SITE_KEY` = Site Key（普通变量，构建时用）
   - `TURNSTILE_SECRET` = Secret Key（Secret）

### 3. 设置一个随机盐
- `IP_SALT` = 任意一串随机字符（32 位以上，Secret）。用来给访客 IP 做不可逆的哈希，用于限频，不存真实 IP。

### 4. 用 Access 保护管理页（只有作者能进）
1. 控制台 → Zero Trust → Access → Applications → Add an application → Self-hosted。
2. 域名 `xinran.wiki`，路径加三条：`/admin`、`/admin/*`、`/api/admin/*`。
3. Policy：Action 选 Allow，Include 选 Emails，填作者本人的邮箱；登录方式用 One-time PIN（邮箱验证码）。
4. 创建后记下：
   - 应用的 **Audience (AUD) Tag**
   - Team domain（形如 `xxxx.cloudflareaccess.com`）
5. 回到 Pages 项目的变量里添加：
   - `ACCESS_AUD` = AUD Tag
   - `ACCESS_TEAM_DOMAIN` = Team domain（不要带 `https://`）
   - `ADMIN_EMAILS` = 作者邮箱（可选，多一层白名单，逗号分隔）

## 设完之后
**重新部署一次**（Deployments → 最新一条 → Retry deployment，或者推一个新提交），因为 `PUBLIC_TURNSTILE_SITE_KEY` 是构建时读取的，绑定和变量也要新部署才生效。

## 验证
1. 浏览器打开 `https://xinran.wiki/api/annotations?page=/blog/hello-world/`，应返回 `{"annotations":[]}`。
2. 打开任意一篇文章，选中一句话，旁边出现「批注」按钮，提交成功后那句话被高亮。
3. 打开 `https://xinran.wiki/admin/`，应先跳到 Access 的登录页，用邮箱验证码登录后能看到批注列表。
4. 用另一个浏览器（没登录）直接访问 `https://xinran.wiki/api/admin/annotations`，应返回 401 或被 Access 拦截。

## 注意
- **不要**把 `TURNSTILE_SECRET` 或 `ACCESS_AUD` 设成 `__dev_skip__`。那是本地测试用的开关，会跳过验证，线上设了就等于没有保护。
- 想在本地测：`npm i -D wrangler`，构建后 `npx wrangler pages dev dist --d1 DB=local --binding TURNSTILE_SECRET=__dev_skip__ ACCESS_AUD=__dev_skip__`，管理接口带请求头 `x-dev-admin: 邮箱`。
